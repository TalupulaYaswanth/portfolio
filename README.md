# Talupula Yaswanth - Portfolio & Web CV

Modern, responsive, multi-page portfolio and interactive Web CV for **Talupula Yaswanth** — Computer Science & Engineering undergraduate with a strong foundation in algorithmic problem-solving, full-stack architecture, and machine learning systems.

---

## 🌟 Pages Overview
- **Home (`index.html`)**: Clean, focused hero introduction, availability status, summary narrative, and quick navigation.
- **Competencies (`competencies.html`)**: Technical skills matrix across Core Engineering, Full-Stack Development, AI & Machine Learning, and Problem Solving with clean interactive badges.
- **Projects (`projects.html`)**: Featured system showcases including Reinforcement Learning Recommender, Automated Code Sandboxing Platform, and ML Recruitment Analytics Suite with interactive architecture modals.
- **Resume & Track Record (`resume.html`)**: Algorithmic milestones (500+ LeetCode streak), education timeline, and 1-click ATS 1-page PDF export engine.
- **Contact (`contact.html`)**: Communication channels, direct email, location, and profiles.

---

## 🚀 Features
- **Dark & Light Mode**: Persistent theme switching with zero flicker and cross-tab synchronization via `localStorage`.
- **ATS Resume Export**: Dedicated print stylesheet (`css/print.css`) producing a 1-page ATS-compliant recruiter resume when printing or saving as PDF (`Ctrl+P` or via the export button).
- **Zero-Dependency Vanilla Stack**: Pure HTML5, modern CSS3 with custom properties, and modular JavaScript (`js/data.js` and `js/app.js`).
- **Single Source of Truth**: All candidate info, project specs, and links are easily configurable in `js/data.js`.
